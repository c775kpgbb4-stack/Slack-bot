# Goody's Slack Bot

A custom Slack bot built with Node.js and Socket Mode for Hack Club Stardance!

## Commands
* `/goody-ping` - Checks if the bot is active and responds with Pong!
* `/goody-roll` - Rolls a 6-sided die.
* `/goody-quote` - Outputs a tech/programming quote.
* `/goody-welcome` - Greets the user.

## Tech Stack
* Node.js
* `@slack/bolt`
* Socket Mode
